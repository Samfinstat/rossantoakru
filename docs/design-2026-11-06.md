# Редизайн Россантпак — 06.11.2026

## Основание

Пользователь попросил изменить внешний вид, взять за ориентир навигацию и карточку TUTORRA, композицию блоков «Город-Курорт», вернуть цвета логотипа и создать иллюстрации. Публикация всей версии в Samfinstat/rossantoakru разрешена.

Визуально просмотрены https://tutorra.ru/, https://tutorra.ru/materials/test-klass-5-iq/ и https://samfinstat.github.io/turysamara/. Оригинальный SVG логотипа извлечён из сохранённого HTML https://rossantpack.ru/contacts/. HTTP 500 источника отмечен отдельно; SVG присутствовал в ответе.

## Решения

- Двухуровневая шапка: логотип, раскрываемый каталог, поиск, контакт и расчёт; ниже прямые ссылки на основные направления и страницы компании.
- Цвета из исходного SVG: #2a4194, #4385c6, #969797, #b3b3b3. Белый и светло-серый фон, тёмный основной текст.
- Главная: предложение → направления → задачи → реальные примеры → материалы → подготовка запроса → FAQ → расчёт.
- Категории: изображения направлений, карточки, чередование иллюстрированных смысловых блоков, смежные решения.
- Карточка товара: ограниченная по высоте фотография с object-fit: contain, увеличение по клику, краткие параметры из исходного описания, запрос с названием товара, раскрываемое полное описание, похожие изделия той же категории. Оригинальные описания доступны в HTML.
- Адаптивная версия: отдельное меню, компактный поиск, карточки и текст без горизонтального переполнения.
- Форма по-прежнему готовит письмо / текст для копирования; автоматическая отправка не заявляется.

## Изображения

Сгенерированы восемь иллюстраций: hero, foam, boxes, plastic, caps, hands, materials, process. Они экспортированы в WebP в site/assets/design/. Это концепции оформления, материалов и подготовки запроса, а не доказательство ассортимента, фотографий цеха или конкретного изделия. В интерфейсе есть соответствующие подписи. Исходные товарные фото сохранены; отсутствующее фото заменяется явно подписанной иллюстрацией направления.

## Участие Claude

Задача 712815b9-5e18-4b82-ab20-16b23c12a4ff передана через PB Claude — связь с Mac mini по прямому поручению пользователя. Claude получил описания наблюдаемых референсов, палитру и план, а не прямой доступ к браузеру или файлам. Учтены замечания о пропорциях фото, краткой карточке, раскрываемом описании, доступности управления и маркировке концептуальных изображений. Визуальную проверку реализации выполнил основной агент.

## Проверка

- Вся сборка проверяется tools/check.py: HTML, внутренние пути и изображения, SEO-метаданные и JSON-LD. Актуальные числа — docs/validation.json.
- В браузере проверены главная, раскрываемый каталог, товар, увеличение фото, раскрытие описания, подсказки поиска и выдача запроса «тубус» (51 результат).
- Главная, товар и категория проверены в iframe viewport 390 px (доступная ширина с полосой прокрутки 375 px), без горизонтального переполнения. Проверено открытие мобильного меню.
- Страницы сохраняют noindex,nofollow; публикация остаётся клиентским предпросмотром.
