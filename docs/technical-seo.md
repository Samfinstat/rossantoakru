# Техническое SEO — Россантпак

## Ключевой принцип
Демонстрационный сайт строится на URL старого сайта; нельзя запускать одновременно две индексируемые копии. Пока версия согласовывается, все страницы имеют `noindex,nofollow`, `robots.txt` закрывает обход, а canonical демонстрационных страниц указывает на целевые URL rossantpack.ru. **Не переносить эти параметры на боевой домен до подготовки релиза.**

## При переносе
1. Проверить сервер и CMS: в аудите от 05.11.2026 зафиксированы HTTP 500 у значительного количества страниц, в том числе сбой sitemap. Исправление обязательно до запуска.
2. Получить полный актуальный экспорт Битрикс по инфоблокам, XML_ID, CODE, секциям, фотографиям, ценам и характеристикам. Пока представлены только 27 подтверждённых карточек крышек, а остальные категории служат стартовой структурой.
3. Сохранить действующие SEO-URL для разделов и товаров с трафиком. Для изменяемых URL — точечные 301, не массовый редирект на главную. Учесть дубли по материалам и назначению.
4. Проверить title, description, H1, canonical, Open Graph, BreadcrumbList, Product (без offers/price при отсутствии публичной цены), Organization. FAQ-разметку использовать только для видимых фактических FAQ и когда она уместна.
5. Настроить sitemap.xml, robots.txt, HTTP 200/301/404/410, поиск, фильтры, пагинацию, формы без дублей, кэш и скорость; абсолютные канонические URL https.
6. Индексируемые категории — только с реальным предложением, релевантным текстом, товарами и самостоятельным поисковым интентом. Не выпускать автоматически тысячи тонких страниц.
7. Заявки отправлять через серверный endpoint в Битрикс24: CSRF, согласие на обработку данных, антиспам, уведомление пользователю только после ответа сервера, логи интеграции.
8. Проверить производительность (LCP, CLS, INP), мобильную навигацию, доступность, размеры изображений WebP/AVIF, alt, lazy loading, HTTP кеширование.
9. Выстроить региональную стратегию по проверенным филиалам и фактической логистике. Не плодить дорвеи с названиями городов.
10. После утверждения — убрать noindex и блокировку robots, назначить правильные canonical и sitemap, подключить Яндекс Вебмастер/Метрику и при необходимости Google Search Console.

## Семантика
`docs/query_map.csv`: 3182 запроса с сохранением исходных пяти показателей частотности, предварительной группой, URL и статусом. Частотность выгружена для **Яндекса без региона**, период замера не подтверждён. `provisional` — предварительная категория, `review` — не определена, `informational` — нужен анализ информационного намерения, `exclude` — предварительное исключение. Требуется SERP-кластеризация по целевому региону, проверка повторов/пересечений и ручное утверждение.
