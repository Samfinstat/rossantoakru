# Россантпак — сайт для согласования

**Обновлено 06.11.2026: аудит и редизайн с обсуждением структуры с Claude.**

Предпросмотр: https://samfinstat.github.io/rossantoakru/

B2B-каталог упаковки с запросом расчёта. **Без корзины и онлайн-оплаты.** Рабочий rossantpack.ru не изменялся.

## Что находится в проекте

- 62 категории и направления, 274 карточки из сохранённого каталога и актуальных списков сайта.
- 155 карточек с исходными описаниями; для остальных подготовлены редакционные описания задачи, требующие уточнения характеристик. 226 карточек имеют фотографии из источника; у остальных фото отсутствуют. Это не утверждение о текущем ассортименте или наличии.
- 11 страниц услуг, 6 страниц материалов, 6 статей; каталог, производство, контакты, запрос расчёта, SEO-карта и два сохранённых прежних адреса крышек.
- 370 обычных HTML-страниц и отдельная страница 404.
- 3182 запроса Topvisor с пятью исходными частотностями. Предварительное лексическое распределение: 2808 кандидатов, 272 требуют проверки, 63 информационных, 39 исключены. Региональная SERP-кластеризация не выполнена.
- SEO-паспорт на каждой странице, полные карты URL и запросов, отдельные H2/H3, метатеги, Open Graph, BreadcrumbList и Product/CollectionPage/Article JSON-LD по типу страницы.

## Дизайн

Меню с прямыми ссылками, поиск по каталогу, палитра оригинального логотипа и иллюстрированные блоки. Товарная карточка использует ограниченную по высоте фотографию, увеличение, краткие параметры и раскрываемое описание. Восемь созданных иллюстраций подписаны; они не заменяют реальные товарные фотографии. Подробнее: [решения и проверка дизайна](docs/design-2026-11-06.md).

## Сборка и проверка

```bash
python -m pip install -r requirements.txt
python tools/prepare.py
PAGES=1 python tools/build.py
python tools/check.py
python tools/publish_root.py
```

`prepare.py` воспроизводит карту семантики из `data/source/topvisor.csv`. Он не перезаписывает редакционные данные категорий и товаров. `merge_content.py` — отдельная операция объединения сохранённых источников, не часть штатной сборки.

Для локального просмотра без префикса: `python tools/build.py`, затем `python -m http.server 8000 --directory dist`.

## Публикация

Существующая публикация Pages берёт файлы из корня `main`. Генератор сначала создаёт `dist`, проверки проходят по всему сайту, затем `publish_root.py` зеркалирует результат в корень. Он удаляет только собственные старые файлы из `.generated-files.json` и защищает каталоги исходников. Перед commit всегда выполняйте все четыре команды выше.

Workflow `Validate SEO review` проверяет сборку и соответствие закоммиченных страниц исходникам. Публикацию выполняет штатный `pages build and deployment`; второго конкурирующего deploy нет.

## Ограничения версии

- Все страницы закрыты `noindex,nofollow`. Canonical и URL страниц в разметке указывают на preview. Подкаталог `/rossantoakru/robots.txt` не управляет индексацией всего хоста github.io. Noindex не делает сайт приватным.
- `sitemap.xml` для индексации не выпускается до готовности production. Инвентаризация URL есть в `review-data/url-inventory.json`.
- Форма открывает черновик почтового письма либо показывает текст для копирования. **Заявка автоматически не отправляется и в Битрикс24 не сохраняется.**
- Ранее рабочий сайт возвращал HTTP 500 при сохранённом HTML-контенте. На проверенной карточке обнаружена ошибка `TSolution\Basket` в footer. Часть последующих запросов не прошла сетевой доступ из среды аудита; это отдельно отмечено в источниках и не названо ошибкой сайта.
- Перед рабочим запуском нужны сверка характеристик/фото, региональная семантика, CRM, юридические документы, аналитика и карта миграции.
