# Россантпак — SEO-прототип нового сайта

Статический проверочный сайт с коммерческой архитектурой «заказ на изготовление», **без корзины и оплаты**. Основой служат 3182 запроса Topvisor, действующая структура разделов rossantpack.ru, обзор реального сайта и 27 товарных карточек крышек из подготовленной ранее выгрузки.

## Содержание

- `tools/prepare.py` — классификация исходной семантики и подготовка данных категорий/крышек.
- `data/categories.json` — 61 реальное направление и подраздел из исходной карты проекта.
- `data/products.json` — 27 карточек крышек с уникальными SEO-данными и полным текстом.
- `docs/query_map.csv` — карта 3182 запросов с исходными метриками и предварительным назначением URL.
- `docs/site_tree.csv` — структура URL сайта и подтверждённых товаров.
- `docs/technical-seo.md`, `docs/migration.md` — технические правила и миграция.
- `tools/build.py`, `site/assets/` — генератор HTML, CSS, JS.

## Локальный просмотр

Нужен Python 3 с установленным `beautifulsoup4`. Из корня: `python tools/build.py`, затем `python -m http.server 8000 --directory dist` и открыть http://localhost:8000.

Для GitHub Pages: `PAGES=1 python tools/build.py`. В `.github/workflows/pages.yml` сборка запускается автоматически после push; Pages нужно включить в настройках репозитория (Source: GitHub Actions). Адрес демонстрации: https://samfinstat.github.io/rossantoakru/.

## Статус и ограничения

В режиме согласования стоит `noindex,nofollow` и `robots.txt: Disallow /`. Формы лишь открывают черновик почтового письма — серверной отправки и связи с Битрикс24 ещё нет. Все цены, сроки и наличие требуют подтверждения. Изображения-заглушки схематические, не являются фото продукции.

Семантика сгруппирована автоматически **предварительно**, не является результатом полноценной региональной SERP-кластеризации. Детальное наполнение остальных товаров потребует актуального экспорта каталога Битрикс, изображений и согласования данных.
